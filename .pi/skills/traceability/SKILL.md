# 可溯源产物规范

## 溯源
- 每个事件标注与结论都要附**可点击的来源 URL**，优先官方公告/官方博客/权威媒体。
- 记录数据**来源、抓取时间、口径**（复权方式、区间、频率），形成可复核的数据 manifest。
- HTML 用"数据来源与口径"表；Office 文档设独立"来源"页。

## 自包含 HTML（安全与跨域）
- Plotly JS 与数据全部**内联**进单个文件，不引用任何 CDN / 外部脚本 / 外部样式。
- 页面加载零自动网络请求；`file://` 双击即可打开，断网可用。
- 外部来源链接仅在用户点击后由浏览器主动发起。
- 外链统一 `target="_blank"` 与 `rel="noopener noreferrer"`。

## Office
- Excel 保留可复核的明细 sheet 与指标 sheet；PPT/Word 的关键数字与管线一致。
- 所有产物标注"历史表现不代表未来、不构成投资建议"。

## 密钥
- 任何密钥不得入库，也不得出现在前端产物中；数据/产物的生成只用免费无 key 的公开数据源。
