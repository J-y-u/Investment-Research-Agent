# 事件归因方法论

## 核心原则
1. **时间相关性 ≠ 因果**：匹配只说明事件与拐点在时间上接近，不证明因果关系。
2. **硬约束窗口**：事件仅在以拐点为中心、±N 个交易日的窗口内匹配；窗口外不配对。
3. **宁空不凑**：配不上事件的拐点显式标注"无重大已知事件（未归因）"，绝不硬凑。
4. **一一对应**：一个事件最多匹配一个拐点、一个拐点最多匹配一个事件，按交易日 lag 最小优先。

## 方向判定
- 以**事件基本面方向（valence）**为准：利好 / 利空 / 中性。
- **不**由拐点类型推断（高点不等于利空、低点不等于利好）。
- 计算事件**后** 1/5/20 个交易日的实际收益作为市场反应证据。
- 当事件性质与短期实际反应方向强烈冲突时，标注冲突并下调置信度（可能受大盘、利好出尽等影响）。

## 影响评级（1–5）
- 市场反应强度：按事件后多窗口中最大绝对收益分档。
- 先验重要度（weight）：由事件本身的行业重要性给出。
- 综合评级取二者较大者，避免重大事件被短期波动低估、平淡事件被波段幅度夸大。
- 置信度：未确认拐点 / 方向冲突 → low；lag 小且一致 → high；其余 medium。

## 局限
- 未引入大盘对照时，事件后收益包含大盘等非事件因素，属"时间关联的市场反应"，非纯因果的超额收益。
